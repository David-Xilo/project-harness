# Security

## Reporting a vulnerability

Report it privately: on GitHub, open the repository's **Security** tab and choose
**Report a vulnerability**. Please do not open a public issue for it.

## What counts

The skills are instructions that Claude Code follows in your projects. A skill that tells
Claude to run untrusted input, to send data outside the machine, or to skip a safety step
of Claude Code is in scope.

## Supported versions

Only the latest release gets fixes.
