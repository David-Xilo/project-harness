# Contributing

Issues and pull requests are welcome. For a large change, open an issue first.

- Branch from `development` and open the pull request against it. `main` only moves at a
  release.
- A skill lives in `desk/skills/<name>/SKILL.md`, with its frontmatter `name` and a
  `description` that says when to use it. Detail goes in `references/` beside it.
- Check a changed skill in a real session before you open the pull request: run
  `/reload-plugins`, then use the skill once on real material.
- Commit subjects read `<area>: <what changed>`, in short plain sentences.
